# Configuration reference

The exhaustive tree, option by option, with the type, the default and what it decides. It is generated from
the configuration classes of the bundle, so it cannot drift from what the container validates.

Until it is generated into this page, `bin/console config:dump-reference beffroi` prints the same thing from
your own installation, including the sections your version actually has.
