# Errors

An error is either redirectable, in which case it goes to the client at a redirect URI that was validated
first, or it is not, in which case the person sees a page and the client learns nothing. Confusing the two is
how an open redirector is born.

This page will list the error codes, say which are redirectable, and describe what is recorded about each.
