# Consent

Consent is recorded, scoped to a client and a person, and it extends itself rather than being rewritten when
a client asks for more. A person reads what they agreed to and takes it back from their account pages, and a
command does the same thing for an operator.

This page will describe the model, when a person is asked again, and what revoking consent takes away.
